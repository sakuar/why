# why · 四个小众创意小站

> 一组纯前端单文件小玩具。无后端、无依赖、无构建，双击即开。
> 在线访问 👉 **https://sakuar.github.io/why/**

## 包含什么

| 小站 | 一句话 | 亮点 |
|------|--------|------|
| 🌍 [此刻地球的夜晚](earth-night.html) | 看全球真实的昼夜分界线 | 逐像素计算太阳高度角，37 座城市，按当地时段配诗 |
| 💻 [假装在工作](fake-work.html) | 终极摸鱼神器 | 编译/下载/训练/扫描/部署 5 种假日志 + 代码雨，可全屏 |
| 🌱 [像素花园](pixel-garden.html) | 按真实时间生长的像素植物 | localStorage 持久化，关掉网页也在长，可浇水加速 |
| 🎲 [一句话决定器](decision-maker.html) | 把纠结交给荒诞 | 抛硬币/塔罗/摇卦等 6 种占卜 + 一本正经的判词 |

## 技术

- 纯 `HTML + CSS + 原生 JS`，每个站点是一个自包含的 `.html` 文件
- 无任何第三方库、无网络请求；数据只存在浏览器本地（localStorage）
- `🌍 地球的夜晚` 使用真实天文算法（太阳赤纬 + 时角）实时绘制昼夜线

## 本地运行

直接双击 `index.html`，或在目录下起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
