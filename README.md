# 📐 几何之旅 · 从点到线到面到体

> 一组纯前端单文件几何教学小站。核心信念：**几何是一体的 —— 从 0 维的点，到 1 维的线、2 维的面、3 维的体，一路生长。**
> 拖动参数，亲眼看见每个公式怎么长出来。无后端、无依赖、无构建，双击 `index.html` 即开。

## 设计原则

- **重模拟，轻文字** —— 不背公式，让参数滑块和动画把公式「长」出来
- 统一的两个动作贯穿全部：**剪拼**（有限刀，等积变换）与 **逼近 / 扫掠**（无限细分）
- 每页 = 大画布 + 参数面板（并排）+ 实时数字 + 公式卡 + 一句话原理
- 每个站点是一个自包含的 `.html`，纯 `HTML + CSS + 原生 JS`，无任何第三方库

## 规划中

点的运动轨迹 · 正多边形 · 扇形/弓形/圆环 · 棱柱棱锥 · 多面体欧拉公式（V−E+F=2）
